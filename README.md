Dyad is a local, open-source AI app builder. It's fast, private, and fully under your control — like Lovable, v0, or Bolt, but running right on your machine.

[![Image](https://github.com/user-attachments/assets/f6c83dfc-6ffd-4d32-93dd-4b9c46d17790)](https://dyad.sh/)

More info at: [https://dyad.sh/](https://dyad.sh/)

## 🚀 Features

- ⚡️ **Local**: Fast, private and no lock-in.
- 🛠 **Bring your own keys**: Use your own AI API keys — no vendor lock-in.
- 🖥️ **Cross-platform**: Easy to run on Mac or Windows.

## 📦 Download

No sign-up required. Just download and go.

### [👉 Download Latest Official Release](https://www.dyad.sh/#download)

### 🚀 Continuous & Per-Commit Builds
You can download the Windows desktop app built fresh on every commit:
- **GitHub Releases (Nightly / Continuous)**: Head over to [Releases](https://github.com/dyad-sh/dyad/releases) for the latest automated continuous builds.
- **GitHub Actions Artifacts (Every Commit)**: Go to the [Actions tab](https://github.com/dyad-sh/dyad/actions/workflows/build-windows.yml), click the latest workflow run for your branch/commit, and download `Dyad-Windows-Installer` (`.exe`) or `Dyad-Windows-Portable` (`.zip`).
